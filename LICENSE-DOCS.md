credit the source, do not use it commercially, and license what you make from it
the same way.

## Why the writing and the code differ

Creative Commons say plainly: *"We recommend against using Creative Commons
licenses for software."* CC licences say nothing about source distribution or
patent rights, and do not compose with software licences — so the code is
covered by [LICENSE.md](LICENSE.md) instead.

The reverse is also true. PolyForm is drafted for software and reads oddly
applied to an essay, and CC is what the rest of the world already uses for
written work. So each half of the project uses the licence built for it.

The intent is the same on both sides: **research and internal use are welcome,
selling it is not.**

## Which is which

Source code, build scripts, configuration and task files are code, and are
covered by [LICENSE.md](LICENSE.md). Everything written to be read by a person
rather than executed is documentation, and is covered by this file.

Where a file is both — a tutorial with code samples in it — the samples are code
and the prose around them is documentation.
